## 📘 Project Overview

This repository contains hands-on practice with file handling in **Node.js**. It includes CRUD operations implemented using different approaches:

- 📂 **sync** – File operations using synchronous methods  
- 📂 **async** – File operations using asynchronous callbacks  
- 📂 **promises** – File operations using Promises  
- 📂 **await_async** – File operations using async/await

This project is useful for understanding different patterns of I/O in Node.js.
